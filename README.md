# IABD - Curso de Especialización en Inteligencia Artificial y Big Data

Repositorio personal con apuntes, prácticas, ejercicios y trabajos realizados durante el **Curso de Especialización en Inteligencia Artificial y Big Data (IABD)**.

## 📁 Estructura del repositorio

```text
IABD/
├── BDA/    # Bases de Datos Avanzadas
├── MIA/    # Modelos de Inteligencia Artificial
├── PIA/    # Programación de Inteligencia Artificial
├── SAA/    # Sistemas de Aprendizaje Automático
├── SBD/    # Sistemas de Big Data
└── README.md
```

### BDA — Bases de Datos Avanzadas

Material relacionado con bases de datos y procesamiento de datos, incluyendo prácticas con **Apache NiFi**.

### MIA — Modelos de Inteligencia Artificial

Apuntes y material relacionado con los fundamentos y modelos de **Inteligencia Artificial**.

### PIA — Programación de Inteligencia Artificial

Ejercicios y prácticas de programación utilizados para aprender y trabajar conceptos necesarios para Inteligencia Artificial.

Incluye:

* Python
* Listas y estructuras de datos
* Ejercicios de programación
* Jupyter Notebooks

### SAA — Sistemas de Aprendizaje Automático

Material relacionado con **Machine Learning** y sistemas de aprendizaje automático.

### SBD — Sistemas de Big Data

Actividades y trabajos relacionados con **Big Data**, incluyendo material sobre almacenamiento, procesamiento y visualización de datos.
